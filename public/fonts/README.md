# Fonts

The design system uses these typefaces (substitutes until licensed files are added):

| Token | Spec face | Current substitute | Weights |
|-------|-----------|-------------------|---------|
| `--font-whyte-inktrap` | Whyte Inktrap | Inter | 300, 400, 500, 700 |
| `--font-whyte-inktrap-mono` | Whyte Inktrap Mono | JetBrains Mono | 400 |
| `--font-grandslang` | GrandSlang | Playfair Display | 300, 400 (italic) |
| `--font-system-ui-karla` | Karla | Karla | 600, 700 |

To use the spec faces, drop WOFF2 files here and update `src/app/layout.tsx`:

- `WhyteInktrap-*.woff2`
- `WhyteInktrapMono-Regular.woff2`
- `GrandSlang-*.woff2`
